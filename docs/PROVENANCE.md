# Provenance and restoration

The original campaign website and its existing Git history are retained in this repository's history. A complete-history backup was verified before restoration.

Original campaign articles, biography, photographs, PDF and video remain historical source material. Topic summaries are brief navigation descriptions; the article copy is preserved in `content/archive.json`. No new campaign promises, current office-holder claims, photograph locations or dates were invented. The site identifies the content as archival throughout.

The recovered implementation used third-party themes, jQuery plugins, font packages and slider/PHP components. Their original files and notices remain available in historical commits and the backup. The maintained pages now use newly written `assets/site.css` and `assets/site.js`; unused vendor bundles and copied template pages were removed from the current tree.

Favour Ojo directed the October 2026 restoration with Codex assistance. This does not establish authorship of original campaign copy, photographs, media or third-party themes. No blanket redistribution license is asserted for those materials. GitHub showed the repository as public at publication. Visibility is controlled by its owner; this restoration did not change that setting or deploy public website hosting.
